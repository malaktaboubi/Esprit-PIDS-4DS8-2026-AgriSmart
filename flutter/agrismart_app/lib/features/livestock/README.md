# Livestock Module

Intelligent Livestock Management with multimodal interaction.

## Structure
- `screens/` - UI screens for livestock monitoring and management
- `services/` - Services for livestock data management
  - Speech-to-Text (Whisper) integration
  - Local LLM (Ollama) interface
  - Offline data management
- `models/` - Data models for livestock records, health data, feeding schedules

## Features
- Voice-based data entry and queries
- Livestock health tracking
- Feeding schedule management
- Breeding records
- Hands-free assistant for field use
