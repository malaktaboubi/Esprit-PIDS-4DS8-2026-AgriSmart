# Satellite Module

Satellite Crop Analysis & Planning using Copernicus Sentinel-2 imagery.

## Structure
- `screens/` - UI screens for satellite imagery and field analysis
- `services/` - Services for satellite data processing
  - Sentinel-2 API client
  - NDVI calculation and visualization
  - VRA map generation
- `models/` - Data models for field boundaries, NDVI data, VRA maps

## Features
- Field selection and boundary definition
- NDVI (Normalized Difference Vegetation Index) visualization
- VRA (Variable Rate Application) maps
- Temporal analysis of field health
- Fertilization planning recommendations
