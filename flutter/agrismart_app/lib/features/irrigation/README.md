# Irrigation Module

Autonomous Irrigation AI Agent interface for IoT-based smart irrigation.

## Structure
- `screens/` - UI screens for irrigation monitoring and control
- `services/` - Services for AI agent communication and sensor data
  - MQTT client for real-time sensor data
  - Weather API integration
  - AI decision engine interface
- `models/` - Data models for irrigation schedules, sensor readings, weather data

## Features
- Real-time soil moisture monitoring
- Weather-based irrigation predictions
- Manual/automatic irrigation control
- Historical data visualization
- AI agent recommendations
