# Core Module

Shared utilities and common code used across all features.

## Structure

### constants/
Application-wide constants:
- API endpoints
- Configuration values
- Asset paths
- App-level settings

### theme/
UI theming and styling:
- Color schemes
- Typography
- Component themes
- Dark/light mode configurations

### utils/
Utility functions:
- Date/time formatters
- Validators
- Helpers
- Extensions

### widgets/
Reusable UI components:
- Custom buttons
- Loading indicators
- Error displays
- Common layouts
